# Смотритель маяка

Расслабляющая игра для Godot 4 о тихом ночном море. Ты — смотритель маяка:
вращаешь луч света и мягко ведёшь заблудившиеся корабли в гавань мимо рифов.
Проиграть невозможно — можно только светить, слушать и доводить корабли до рассвета.

**Вся графика и весь звук создаются кодом во время работы игры — в проекте нет
ни одного изображения или аудиофайла.** Каждый запуск звучит и выглядит чуть иначе.

## Как это выглядит и работает

- **Живое море.** Море нарисовано слоями светящихся гребней волн, лунной дорожкой,
  биолюминесцентным планктоном и бликами света маяка на воде.
- **Объёмный луч.** Три вложенных слоя конуса света с пылинками и мягким мерцанием.
- **Корабли-силуэты** с тёплым фонарём и светящимся кильватером идут за лучом.
- **Ночные циклы.** Провёл нужное число кораблей — наступает рассвет, палитра меняется,
  море отдыхает. С каждой ночью туман густеет и рифов становится больше.
- **Генеративный эмбиент.** Шум волн и ветер синтезируются как зацикленные буферы,
  редкие ноты пентатоники и колокола гавани — аддитивный синтез с реверберацией.

## Запуск

1. Открой Godot 4.3 или новее (проверялось на 4.7.2).
2. Во вкладке «Управление проектами» нажми **Импорт**, выбери файл `project.godot` из этой папки.
3. Если редактор предложит обновить конфигурацию проекта — согласись.
4. Нажми **F5** (Запустить проект).

## Управление

| Действие | Управление |
| --- | --- |
| Вращать луч маяка | Движение мыши |
| Всплеск планктона | Левая кнопка мыши |
| Ударить в колокол | Пробел |
| Пауза и громкость | Esc |

## Цель

Проведи корабли к огням гавани справа. Счётчик в левом верхнем углу показывает
прогресс ночи. Корабль, который ведут светом, подсвечивается бирюзовым ореолом.
Рифы и остров остановят корабль мягким «туком» — просто обведи их лучом и продолжай путь.

## Структура проекта

```
project.godot              — настройки проекта
scenes/main.tscn           — единственная сцена
scripts/main.gd            — игровая логика, ночные циклы, UI
scripts/sea.gd             — процедурная отрисовка моря, неба, маяка, гавани
scripts/ship.gd            — корабли: движение, кильватер, свечение
scripts/beam.gd            — объёмный луч маяка
scripts/audio_director.gd  — генеративный звук (синтез в рантайме)
shaders/post.gdshader      — постобработка: зерно плёнки, виньетка, грейдинг
```
